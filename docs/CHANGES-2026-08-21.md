## 任务 B：侧边栏显示修复

### 问题描述

点击 🐳 按钮后，看到模糊 backdrop 但侧边栏空白。

### 根因

DSH 应用 CSS 对 `.Obn01a_sidebarCol` 设置 `will-change: transform`，导致 `position: fixed` 元素渲染异常。

### 解决方案

添加 `display: block !important` 强制覆盖。
